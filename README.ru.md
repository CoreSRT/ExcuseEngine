# ExcuseEngine

*Рандомайзер для тех, кто не до конца уверен, что ему нужен честный рандомайзер.*

Знаешь это чувство. Посмотреть фильм, который не особо-то и хочется? Съесть ещё одно пирожное на ночь? (ДА! ДА! ДА!!!)

В глубине души ты уже знаешь ответ. Но иногда нужен небольшой толчок — или убедительное оправдание. Именно для этого и нужен **ExcuseEngine**.

Выставляешь вероятность ползунком (или вводишь цифрами), жмёшь кнопку — и получаешь ответ: **Да** или **Нет**. Зелёный — вперёд. Красный — «ну, ты сам спросил».

Написан на Python с customtkinter. Выглядит аккуратно, работает без интернета, говорит на 14 языках.

## Что внутри

- **Ползунок вероятности** — от 0% до 100%, шаг 1, с подписями `0%` / `100%`
- **Цифровой ввод** — введи процент и нажми Enter или ✓
- **Результат Да / Нет** — зелёный «Да», красный «Нет», в скруглённой рамке с цветной обводкой
- **Граничные случаи** — 0% всегда «Нет» (ты это знал), 100% всегда «Да» (ты этого хотел)
- **14 языков** — автоопределение по системной локали, выпадающий список для ручного переключения
- **Иконка-кубик** — повёрнутый игральный кубик в заголовке окна, потому что у случайности должен быть талисман

## Поддерживаемые языки

RU, EN, ES, PT, DE, FR, IT, PL, TR, AR, HI, JA, ZH, KO

## Запуск из исходников

```bash
# Создать и активировать venv
python -m venv .venv
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux / macOS

# Установить зависимости
pip install -r requirements.txt

# Запустить
python main.py
```

## Сборка в .exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --icon=icons/icon_dice.ico --add-data "icons/icon_dice.ico;icons" --name "ExcuseEngine" main.py
```

Готовый exe появится в `dist/`.
